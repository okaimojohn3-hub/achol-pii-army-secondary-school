# Achol-Pii Army Secondary School Website

This is a ready-to-host static website built from the school photographs supplied in ChatGPT.

## Included
- Responsive home page
- About section
- Academics section
- Student Life section
- 20-photo school gallery with full-screen viewer
- Contact section
- Mobile navigation
- Modern school-focused visual design
- No database or WordPress required

## Before publishing
Replace the placeholder phone number, email address and any school-specific text in `index.html`.

## How to preview
Open `index.html` in a web browser.

## How to publish
Upload the entire folder to any static hosting service. You can also use the folder with a normal web hosting account and connect a domain name later.
